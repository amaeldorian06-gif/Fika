## 3. Mon apport (commit `0ab205b`)

- **Mode SMTP explicite** (votre demande) : `SMTP_HOST` / `SMTP_PORT` / `SMTP_SECURE` / `SMTP_USER` / `SMTP_PASS`. Port 587 → STARTTLS, port 465 → TLS direct ; incohérence port/secure détectée, corrigée et **affichée à l'admin**. Prioritaire sur Gmail, qui reste en repli.
- **Statut d'alerte enrichi** dans l'admin : mode, serveur, port, chiffrement, avertissements — jamais de secret.
- **Messages d'erreur traduits** selon les codes nodemailer : `EAUTH` (identifiants), `ECONNECTION`/`ETIMEDOUT` (réseau), `EENVELOPE` (destinataire).
- **Tests unitaires : 333/333** (18 dans `notify.test.ts`, dont 6 nouveaux sur la configuration SMTP et la non-exposition des secrets).
